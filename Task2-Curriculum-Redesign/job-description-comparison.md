# Task 2 — Job Description Comparison

**Prepared:** 22 October 2026  
**Career focus:** Full-Stack Software Engineer and AI/ML Engineer  
**Purpose:** Compare skills stated in real employer postings with the regular B.Tech CSE course areas visible in the ICFAI programme screenshots.

## Method and limitations

This is a qualitative comparison of three employer postings, not a statistical survey of the whole job market. Two postings are full-stack roles at Wipro and one is an AI/ML role at Mattel. The Wipro postings reviewed list substantial prior experience (one lists 6–8 years and another lists 6+ years); therefore, their technologies are useful signals of industry skill direction, but their seniority requirements should not be treated as fresher eligibility criteria. The Mattel AI/ML posting lists approximately 4–7 years of relevant experience, so it is also not an entry-level specification.

The curriculum column below uses course titles visible in the supplied ICFAI regular CSE screenshots. A course title alone does not prove that every listed technology is taught in depth; detailed syllabi and learning outcomes would be needed for that conclusion.

## Initial findings

1. The published CSE course list already contains relevant foundations: programming, data structures, algorithms, OOP, DBMS, web technologies, AI, ML, software engineering, testing, cloud computing, big data systems and computer vision.
2. The job postings point toward stronger integration of these subjects through complete, tested and deployed projects—not only isolated theory or demonstrations.
3. The most visible potential update areas are full-stack API integration, modern deployment practices, practical ML evaluation, GenAI/RAG evaluation, MLOps concepts, responsible AI and cross-course project work.
4. These are **provisional gaps inferred from job postings and course titles**. We must check detailed course syllabi before claiming that a topic is absent from the current curriculum.
